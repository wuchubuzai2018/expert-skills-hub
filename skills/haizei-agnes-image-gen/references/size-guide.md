# 尺寸与比例控制指南

本文档说明如何在 Agnes Image 2.1 Flash 中控制输出图片的尺寸和比例。

## 尺寸参数

通过 `-s` 或 `--size` 参数指定尺寸，格式为 `WIDTHxHEIGHT`（宽度 x 高度，单位像素）。

Agnes Image 2.1 Flash 支持任意合法自定义尺寸，相比预设尺寸方案更为灵活。

## 常用预设尺寸

| 尺寸 | 比例 | 适用场景 |
|------|------|----------|
| 1024x1024 | 1:1 | 头像、Instagram帖子、方形构图 |
| 1536x1024 | 3:2 | 标准横版、摄影构图 |
| 1024x1536 | 2:3 | 标准竖版、人物肖像 |
| 1024x768 | 4:3 | 经典横版、演示文稿 |
| 768x1024 | 3:4 | 经典竖版、Pinterest |
| 2048x2048 | 1:1 | 高清方图 |
| 2048x1152 | 16:9 | 横版视频封面、桌面壁纸 |
| 3840x2160 | 16:9 | 4K超高清横版 |
| 2160x3840 | 9:16 | 竖版4K、手机壁纸 |
| 1920x1080 | 16:9 | 全高清 |
| 1080x1920 | 9:16 | 手机竖版 |

## 常见自定义尺寸示例

| 尺寸 | 比例 | 适用场景 |
|------|------|----------|
| 1280x720 | 16:9 | 高清视频 |
| 1080x1080 | 1:1 | Instagram方图 |
| 1440x2560 | 9:16 | 手机竖版2K |
| 1920x1280 | 3:2 | 经典摄影比例 |
| 1280x1920 | 2:3 | 经典竖版摄影 |
| 3840x1600 | 12:5 | 超宽银幕 |
| 1600x3840 | 5:12 | 超长竖版 |

## 使用方法

通过 `-s` 或 `--size` 参数指定尺寸：

```bash
# 使用预设尺寸
node scripts/generate_image.js -p "风景照片" -f "landscape.png" -s "1920x1080"

# 竖版
node scripts/generate_image.js -p "城市夜景" -f "city.png" -s "1080x1920"

# 高信息密度场景（建议较大尺寸）
node scripts/generate_image.js -p "A futuristic city marketplace..." -f "city.png" -s "1536x1024"
```

## 尺寸选择建议

- **文生图**：建议根据目标用途选择合适的比例与分辨率，避免无意义的超高分辨率导致出图时间显著拉长。
- **图生图**：建议与原图保持相近的比例和分辨率，可提升构图保持度。
- **高信息密度场景**：建议使用较大尺寸（如 `1536x1024`、`2048x1152`），保留更多视觉细节。

## 注意事项

1. **尺寸格式**：必须为 `WIDTHxHEIGHT` 形式，例如 `1024x768`。
2. **长宽限制**：建议不要超过 `4096x4096`，避免请求体过大或服务超时。
3. **构图匹配**：图生图时尽量与原图比例相近，有助于保持原构图。
4. **极端比例**：比例超过 `3:1` 的极长/极宽图片生成效果可能不稳定，建议避免。
