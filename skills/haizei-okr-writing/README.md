# OKR Writing Skill

用于将个人工作计划、领导给出的方向和已有实践，整理成可直接填写的季度 OKR。

## 适用场景

- 编写或润色目标名称、目标描述和 4 条举措
- 将模糊方向改写为 SMART 目标
- 按 PDCA 形成个人可执行的行动闭环
- 将“太像解释、太像口号、太像在要求别人”的文字改为自然的第一人称表达

## 使用方式

描述以下信息后调用本 Skill：

1. 季度与目标方向
2. 已经完成的工作或上一季度基础
3. 领导给出的指标、平台能力或边界
4. 期望的文风，例如“可直接填系统”“适合给领导看”“实在一点”

## 典型输入

```text
Q2 已经做了一部分 AI 代码评审。Q3 要继续提升，接入 Memory 和 CodeGraph，
准确率目标 60%；每周盘点拒绝的问题和理由，双周迭代。请写一个 SMART 目标和 4 条本人举措。
```

## 典型输出特征

- 目标含范围、时间、量化结果与交付物。
- 举措使用“我会”描述可落地行为。
- 先盘点事实，再做真实试点，再记录检查，最后双周迭代和沉淀。
- 不虚构数据、平台功能或未确认的业务规则。
