# Edit Checklist

用于已有 Wiki 页面增量修订前后的统一检查清单。

## 修改前检查清单

在修改任意已有 Wiki 页面前，先逐项检查：

1. 本次是补段落、补章节、补索引、补链接，还是必须整页重写。
2. 当前页面哪些部分已经写得好，应该保留。
3. 本次修改是否会影响上级索引页、域入口页、兄弟页面链接。
4. 本次缺口是否可以通过追加内容解决，而不是覆盖原文。
5. 修改完成后需要回查哪些关联页面。

若以上 5 项中，有 3 项以上都能通过局部补写解决，则不要整页重写。

## 修改后完整性检查

完成修订后，至少回查这些内容：

1. 当前页面是否仍然完整，标题和章节顺序是否被意外破坏。
2. 来源索引、Section sources、文件引用是否仍然成立。
3. 上级索引页、域入口页、兄弟页面的交叉链接是否仍然正确。
4. 新增内容是否与当前页面原有口径冲突。
5. 若本次只修局部，是否误删了原来已有的优质内容。

## 使用原则

- 先补局部，再考虑整页重写。
- 先保留已有优点，再考虑统一风格。
- 先检查关联影响，再落笔修改。
- 修改完成后，必须回查本页和相关入口页。
