# 子目录 index.md 模板

## 用途

为每个**子目录**（如 `01-项目概览/`、`02-数据库设计/` 等）创建 `index.md`，承担以下职责：

- 文档清单入口（按编号/标题/状态/日期/文档 5 列登记）
- 子目录归档范围说明
- 字段含义与取值约定

## 模板

````markdown
---
文档编号: DOC-[层级]-[子目录序号]-IDX
标题: [子目录名称] 索引
类型: 索引
状态: 现行
日期: YYYY-MM-DD
作者: [作者/作者组]
---

# [子目录名称]

> 本目录用于归档：**[一句话描述该目录的归档范围]**。

## 文档清单

下表登记本目录下的所有文档，新增/变更/废弃文档时必须同步更新。

| 编号 | 标题 | 状态 | 日期 | 文档 |
|------|------|------|------|------|
| DOC-[层级]-[子目录序号]-001 | 示例文档标题 | 现行 | YYYY-MM-DD | [查看](./DOC-[层级]-[子目录序号]-001-示例文档.md) |

### 字段说明

| 字段 | 含义 | 取值 |
|------|------|------|
| 编号 | 文档唯一编号 | 格式 `DOC-{层级}-{子目录序号}-{3 位序号}`，如 `DOC-PRJ-01-001` |
| 标题 | 文档标题 | 与文档内 YAML 的 `标题` 字段一致 |
| 状态 | 文档生命周期 | `草稿` / `评审中` / `现行` / `已废弃` |
| 日期 | 最近更新日期 | 格式 `YYYY-MM-DD`，与文档内 YAML 的 `日期` 字段一致 |
| 文档 | 文档链接 | 相对路径的 Markdown 链接 |
````

## 占位符说明

| 占位符 | 含义 | 填写示例 |
|--------|------|----------|
| `[层级]` | 所属层级编码 | `PRJ` / `TECH` / `AST` |
| `[子目录序号]` | 该子目录在所属层级中的数字前缀 | `01` / `02` / `05` |
| `[子目录名称]` | 子目录中文名 | `项目概览` / `数据库设计` |
| `YYYY-MM-DD` | 创建或更新日期 | `2026-08-30` |
| `[作者/作者组]` | 文档作者或团队 | `项目组` |

## 字段取值约束

| 字段 | 可选值 |
|------|--------|
| 状态 | `草稿` / `评审中` / `现行` / `已废弃` |
| 编号后缀 | `001` – `999`，按时间顺序递增 |

## 使用方式

1. 在每个子目录下创建 `index.md`
2. 替换 `[层级]`、`[子目录序号]`、`[子目录名称]`
3. 用一句话准确描述该子目录的归档范围
4. 新增文档时在该表格追加一行；修改/废弃时同步更新对应行的 `状态`、`日期`、`文档` 字段
5. 删除示例行（`DOC-[层级]-[子目录序号]-001`）后再写入实际文档条目
