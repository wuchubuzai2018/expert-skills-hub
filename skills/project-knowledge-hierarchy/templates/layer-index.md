# 各层 index.md 模板（层根目录）

## 用途

为项目层、技术层、资产层三个层级的**根目录**创建 `index.md`，承担以下职责：

- 本层目录结构说明
- 归档指引（如何选择子目录）
- 本层文档清单入口

## 模板

````markdown
---
文档编号: DOC-[层级编码]-000
标题: [层级名称]
类型: 索引
状态: 现行
日期: YYYY-MM-DD
作者: [作者/作者组]
---

# [层级名称]

> 本目录为 [层级名称] 的根索引；具体文档请进入对应子目录查阅。

## 目录说明

| 目录 | 用途 | 包含内容 |
|------|------|----------|
| `[01-子目录A]` | [用途] | [包含内容] |
| `[02-子目录B]` | [用途] | [包含内容] |
| ... | ... | ... |

## 归档指引

新增文档时，请根据以下规则选择目录：

- [根据该层各子目录的职责，给出 1-2 句判断标准]

## 文档清单

> 本层文档索引，详细字段说明见 `目录索引模板（子目录 index.md）` 一节。

| 编号 | 标题 | 状态 | 日期 | 文档 |
|------|------|------|------|------|
| - | （暂无文档） | - | - | - |
````

## 层级编码对照

| 层级 | 编码 | 占位符 `[层级编码]` 替换值 |
|------|------|---------------------------|
| 项目层 | `PRJ` | `PRJ` |
| 技术层 | `TECH` | `TECH` |
| 资产层 | `AST` | `AST` |

## 占位符说明

| 占位符 | 含义 | 填写示例 |
|--------|------|----------|
| `[层级编码]` | 层级缩写编码 | `PRJ` / `TECH` / `AST` |
| `[层级名称]` | 层级中文名 | `项目层` / `技术层` / `资产层` |
| `[01-子目录A]` 等 | 该层下子目录的实际名称 | `01-项目概览` |
| `YYYY-MM-DD` | 创建或更新日期 | `2026-08-30` |
| `[作者/作者组]` | 文档作者或团队 | `项目组` |

## 使用方式

1. 在每个层级根目录下创建 `index.md`
2. 替换 `[层级编码]` 与 `[层级名称]`
3. 按该层级实际子目录填写「目录说明」表格
4. 按该层特点撰写「归档指引」（通常 1-3 条）
5. 「文档清单」初始为空，列出占位行即可
